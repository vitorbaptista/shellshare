About Shellshare

Shellshare is a small, open-source tool for showing someone what is happening in a terminal as it happens. Run one command and it prints a browser link. Anyone with the complete link can watch the terminal live, but viewers cannot send keystrokes or commands back. There is no account to create, project to configure, or browser extension to install.

The project is designed for teaching, presentations, pair debugging, support, and long-running engineering work that benefits from a human observer. It is also designed for automation: AI agents and scripts can run a command through shellshare exec --json -- <command>, parse the URL from the first JSON event, and hand that link to a person while the work continues.

Shellshare was created and is maintained by Vitor Baptista. The Rust client and server are published in the Shellshare GitHub repository under the Apache License 2.0. Broadcasts are end-to-end encrypted by default, and the key after # in the share URL is never sent to the server. See the developer documentation for integration and self-hosting details.
