Shellshare is an open-source project rather than a commercial support service. The best place to ask for technical help, report a reproducible bug, or request a feature is the public Shellshare issue tracker on GitHub. Before opening an issue, check the existing reports and include the Shellshare version, operating system, command you ran, expected result, and actual result. Remove passwords, terminal output containing secrets, and complete encrypted room links before posting.

Questions about command-line options and self-hosting may already be answered on the homepage, in the developer documentation, or in the repository README. AI-agent and scripting integrations are documented in llms.txt.

Shellshare is maintained by Vitor Baptista; current public contact links are available there and on the maintainer’s GitHub profile. Do not put exploit details, passwords, terminal contents, or live share links in a public issue. Use a private contact method listed by the maintainer for sensitive reports.
